# Avatara 0.3.1 · Agent

留住思路，继续向前。

Avatara 是一个以个人浏览记忆、当下关注和长期目标为起点的 Chrome 助理。0.3 将对话从“先检索、再回答”升级为原生工具调用循环：模型理解请求后自主选择工具，读取结果，再继续处理或回答；不需要个人资料的讨论直接回答。

旧项目 `D:\DshWorkspace\Avatara_extension` 保持原样；新实现位于 `D:\DshWorkspace\Avatara_next`。新实现不会自动读取或迁移旧扩展的数据。真实扩展首次安装显示空状态，本文所述演示数据只存在于独立的本地演示中。

## 先体验界面

需要 Node.js 20 或更新版本，无第三方运行依赖，也无需构建。直接在新项目目录运行：

```powershell
cd D:\DshWorkspace\Avatara_next
node scripts/preview.mjs
```

在 Chrome 中打开 [独立演示](http://127.0.0.1:4318)。如端口被占用：

```powershell
node scripts/preview.mjs --port 4320
```

演示使用 12 条中文合成记忆、3 个示例目标和本地检索回答，支持收藏、搜索、目标进度、对话、偏好保存、模拟导入与摘录、导出和清空。数据只写入这个 localhost 页面自己的 `localStorage`，与扩展数据完全分开。页面会明确标示「独立演示 · 示例数据」。

**这是一套普通网页模拟运行环境，不是已安装扩展的远程界面。** 它不读取真实 Chrome 历史、不连接扩展后台、不接受 API 密钥，也不发送云端 AI 请求。点击导入或摘录只会增加合成资料。清空后保持空白，不会自动重新填充示例。

预览服务器仅绑定 `127.0.0.1`，只提供界面所需的项目静态资源，不提供整个工作区。新增界面文件后需要重启服务器，让资源白名单更新。按 `Ctrl+C` 停止。

## 安装真实扩展

1. 在 Chrome 中打开 `chrome://extensions`，启用开发者模式。
2. 点击「加载已解压的扩展程序」，选择 `D:\DshWorkspace\Avatara_next`。
3. 将 Avatara 固定到工具栏。在一个普通网页上点击图标，可以记住当前页、打开工作台或打开侧边栏。
4. 先保存一页内容，或进入「记忆」手动导入一段浏览历史，再开始检索和对话。

要求 Chrome 116 或更新版本，使用 Manifest V3。没有打包或编译步骤，直接加载项目目录。修改代码后，在扩展管理页点击重新加载；已经打开的工作台也需要刷新。

可分发的纯扩展压缩包为 `dist/avatara-0.3.1.zip`，解压后加载解压目录即可。运行 `node scripts/package.mjs` 重新生成。压缩包仅包含生产资源，不含演示、测试、开发服务器或凭据。图标由 `node scripts/make-icons.mjs` 从品牌几何图形生成。

扩展使用 `unlimitedStorage` 保存长期本机记忆，避免几百篇正文就触及默认容量上限；该权限不增加网站或历史记录访问范围。磁盘写入失败时会保留已有数据并给出导出提示。

「记住当前页面」需要 Chrome 在用户点击扩展图标时授予的 `activeTab` 权限。最直接的操作是停留在要保存的普通网页上，点击 Avatara 图标，再点击保存。浏览器内部页、扩展商店页等受保护页面不支持采集。在完整工作台中直接点击保存时，如果当前活动页是工作台本身，会提示回到目标网页操作。

## 当前能做什么

| 空间 | 已实现的行为 |
| --- | --- |
| 今日 | 个人称呼与关注方向、最近记忆、进行中目标、本地关键词归类的主题线索、快捷提问。 |
| 记忆 | 中英文关键词检索，匹配标题、正文、域名和已有标签；全部／收藏筛选；来源链接；手动保存当前页面正文；按需导入历史。 |
| 目标 | 记录目标、初衷、数量、单位和日期；逐次推进；达到数量后完成；确认后删除。 |
| 对话 | 云端 Agent 自主选择工具并支持多步调用；展示执行记录与来源；创建目标、更新进度先生成确认卡片；本机模式仅提供明确的检索与目标回顾。 |
| 偏好 | 自动记录开关、历史保留期、排除网站、云端连接、数据导出与确认清空。 |

历史导入读取标题、URL、访问时间和访问次数，每次最多 5,000 条，不下载历史页面正文。相同规范化 URL 合并时，会保留已保存的正文和收藏状态。自动记录默认关闭；获得历史权限并主动开启后，只记录新访问的标题和链接。

### 按日期回顾浏览（0.3.1）

可以问「昨天我都浏览了哪些东西」「最近七天哪些日期有浏览记录」或指定起止日期。新增 `query_history` 工具按设备本地时区查询真实逐次访问，不再用关键词检索的少量结果推测某天是否有记录。同一页面昨天访问、今天再访问，昨天的事件仍可查到。

旧记忆每个网址只有一个最后访问时间，不能还原访问日历；汇总中的 `activeDays` 也不是所有实际活跃日期。日期查询会在已有 `history` 授权下直接核对 Chrome 保留的事件，不要求重新导入，不自动开启采集，也不把查询结果批量写入记忆库。未授权时，只能给出明确标为不完整的旧数据；通过「记忆 → 导入历史」完成授权后可重试。

查询最多覆盖 366 个自然日，每页 1–50 条，支持页面列表与每日计数。单次扫描最多 10,000 个候选网址、50,000 条范围内事件，扫描预算 18 秒；达到上限、读取失败、权限不足都会标明不完整，不能把空结果当作未浏览。未读完分页时也会提示。完整只指本次查询时 Chrome 可提供且未被排除的记录，不包含已删除、无痕或所有设备的历史。

日期查询遵守排除域名；记忆保留期只控制扩展保存的记忆，不会限制或删除 Chrome 自身历史。云端模式只按需发送工具返回的日期统计及每页标题、脱敏链接和访问时间等元数据，不抓取历史页面正文。本机基础模式也支持「昨天／今天／最近七天／最近三十天」的简单浏览回顾，但不具备模型的自由日期理解与自主分页能力。

手动摘录读取用户当前授权网页的主要文本，最多 12,000 字符，并自动收藏。未收藏的旧记忆按照保留期清理；收藏内容不受保留期影响。排除网站影响后续导入和采集，不会回溯删除已有记录。未带标签的标题与正文会按明确的中英文关键词生成最多 4 个主题标签，已有自定义标签保留。主题线索不是对用户全部兴趣的认定。

## 配置云端模型

本机模式无需密钥，使用确定性的检索与建议，不是本地大模型，也不是自主 Agent。需要自然交流与工具调用时，在真实扩展的「偏好设置 → 思考伙伴」中配置：

| 字段 | 默认值／规则 |
| --- | --- |
| 服务地址 | `https://api.deepseek.com`；带 `/v1` 的地址也可填写，内部会统一处理。 |
| 模型名称 | `deepseek-v4-flash`；以你的服务账户实际可用模型为准。 |
| API 密钥 | 手动填写，保存在扩展的 `chrome.storage.session` 中；浏览器会话结束后需要重新输入。 |
| 云端 Agent | 默认关闭。启用前阅读界面中的传输说明，并授予所填服务域名的访问权限。 |

需要支持原生 `tools` / `tool_calls` 的 Chat Completions 服务，仅能返回文本的兼容端点不足以使用 Agent。云端地址要求 HTTPS；本机 `localhost` 或回环地址可使用 HTTP。真实请求发往规范化地址的 `/v1/chat/completions`。不会跟随重定向转发凭据。DeepSeek 端点明确关闭 thinking，避免默认推理模式延长交互及跨轮推理协议要求；其他服务不附带这一专属参数。协议依据：[DeepSeek 工具调用](https://api-docs.deepseek.com/guides/tool_calls/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。

初始请求只包含用户问题、最近 6 条对话与工具定义，不会预先检索或装入整批个人记忆。模型可以按需调用以下工具，其结果才会发送给配置的服务：

| 工具 | 行为与边界 |
| --- | --- |
| `query_history` | 按本地日期读取已授权 Chrome 的逐次访问，分页列页面或按日汇总；返回查询范围、完整性和下一页位置。无权限时只给不完整的本机证据。 |
| `search_memories` / `read_memory` | 搜索少量记忆，再读取选中记录的本机正文；不联网抓取历史页面。 |
| `list_goals` / `get_profile` / `get_activity_summary` | 查看实际目标、用户填写的关注与本机记录概况，不推断未记录的完成情况。 |
| `read_current_page` / `list_tabs` | 读取当前已授权页面或可访问标签页的元数据；不打开、关闭或点击网页，不自动保存正文。 |
| `create_goal` / `advance_goal` | 只生成待确认卡片；点击确认后才写入，拒绝或过期不执行，重复点击不重复计数。 |

每轮最多 6 次模型请求、10 次工具调用；工具参数严格校验。对话展示真实工具回执，不展示内部推理。来源只来自本轮实际读取的记录，数字引用会校验范围。资料明确标为不可信数据，不能授权模型执行页面里的指令。操作卡片有效期 30 分钟；确认时只读取保存的提案，不接受客户端替换参数。目标修改、卡片状态及执行回执一起保存。确认完成后会显示本机回执；下一次提问可继续围绕更新后的目标讨论。

当前不具备任意网页点击、自动填表、联网搜索、文件操作或后台自主行动能力。模型失败会明确报错，不会悄悄降级并伪装成成功的 Agent。

连接测试只发送合成问候，不带个人记忆。API 密钥与普通状态分开保存，不进入导出文件；识别到的常见凭据形式会在文本进入持久状态前被遮蔽。请不要把密钥写入源代码、示例数据或提交文件。

另有一个需要主动运行的真实 Agent 云端冒烟脚本：


凭据文件由一行 API Key 和一行 HTTPS 服务地址组成，放在源码目录外；不要把真实内容粘贴到文档或日志中。该脚本限定连接 `api.deepseek.com`，验证普通聊天零工具、搜索再读正文、创建目标提案及确认、先查询再推进目标、重复批准幂等、合成当前页读取、进度事件与密钥隔离。它只读取指定凭据文件，不读取浏览器配置、真实浏览历史或导出数据。Chrome API 与记录全部来自内存中的合成夹具。普通测试不会启动它；主动运行会消耗提供方 API 用量。

实际扩展仍需要人工核对：首次权限申请、工具栏当前页摘录、侧边栏打开、历史导入、撤销权限、浏览器重启后会话密钥清除，以及已授权的云端调用。

日期冒烟脚本同样仅使用合成 Chrome 数据，验证模型主动选用日期工具、正确找到昨天访问而今天又访问的 12 页、列出每日记录，以及缺少权限时不把空结果解释为没有浏览。日期回答允许最多 100 个已读取来源，普通回答仍限制 6 个，保存对话后不会丢失第 7 个以后的引用。

## 项目结构

```text
Avatara_next/
  manifest.json                  Manifest V3 配置
  index.html                     工作台与侧边栏共用入口
  src/core/                      数据模型、检索、工具注册表、原生 Agent 循环与云端协议
  src/background/                Chrome 权限、存储与请求队列
  src/popup/                     工具栏弹窗与当前页动作
  src/ui/                        共享界面、样式与 SVG 图标
  src/preview/                   独立合成数据和网页演示运行时
  scripts/                       本地服务器、资源检查、可选云端冒烟
  tests/                         核心、运行时和演示测试
  docs/CONTRACT.md                数据与消息接口约定
  docs/DESIGN.md                  产品与视觉设计说明
```

当前交付是第一版完整功能基线。检索尚未使用语义向量或 embedding，目标需要用户记录进度，也没有付款、自动代办交易、任意工具自主执行、书签自动同步或后台日程调度。后续演进应围绕更可靠的记忆质量、可理解的个性化和真实扩展验收展开，而不是让界面承诺尚未具备的能力。
