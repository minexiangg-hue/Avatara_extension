## 2026-09-22 · 0.3.1 日期查询修复

### 原因与修复

原工具仅提供少量关键词检索，没有日期枚举；导入使用 `HistoryItem.lastVisitTime`，记忆按 URL 合并，只保留最后一次访问。因此昨天访问、今天再访问的页面在旧记录里只剩今天。汇总的 `activeDays` 是最后访问日期的去重数，`visitCount` 是网址累计访问次数，都不足以回答实际逐日浏览。没有证据说明用户 9 月 21 日确实没有浏览。

通过开发文档检索并核对 [Chrome 官方 history API 文档](https://developer.chrome.com/docs/extensions/reference/api/history)，使用 `getVisits` 核对逐次事件。候选搜索扩展到当前时间，再按查询日期过滤事件，避免后续重访遮蔽旧日期；API 调用保留 Chrome 返回的原始 URL，模型只收到规范化元数据。新增原生 `query_history` 工具、本地日期边界、每日清单、分页、完整性与权限回退。
